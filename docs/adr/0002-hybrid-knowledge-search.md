# ADR 0002：Runbook 混合检索与版本引用

状态：已采纳（Stage 2A）

## 决策

Runbook 草稿经独立评审后发布不可变版本。发布时对受控 Markdown 分块、生成 1536 维 embedding，并把块、向量和来源版本一同写入 PostgreSQL。只有同服务、已发布版本的块能进入诊断检索；退役版本不再进入新检索，但历史提案仍引用原版本。

查询同时使用 PostgreSQL `simple` 全文检索和 pgvector 余弦距离，分别保留词法与向量排名和分数，再以倒数排名融合。检索结果包含 Runbook key、版本、块 ID 与分块号，供模型引用；最终行动仍必须通过服务端的版本和参数校验。embedding 维度或有限值校验失败时拒绝索引或查询，不静默降级为假向量。

## 原因与后果

`simple` 全文配置保留服务名、错误码和 Runbook 标识的精确匹配；向量补充不同措辞的召回。固定 1536 维是首次部署契约，换模型维度需要显式迁移和重建索引。确定性 Eval 使用固定检索 fixture，只证明版本、引用和评分流程可重复，不代表线上混合检索召回率。
