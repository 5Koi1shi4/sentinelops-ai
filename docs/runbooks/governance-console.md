# 治理控制台

控制台围绕 Runbook 的不可变版本、可追溯证据和 AI 发布阈值组织信息。入口为 `/runbooks`、`/runbooks/:key/versions/:id`、`/evals`；事故详情中的证据条目打开只读抽屉。

## Runbook

具有服务授权的读取角色只能查看已发布版本。`RUNBOOK_ADMIN` 可在授权服务内管理草稿；`PLATFORM_ADMIN` 可跨服务管理。前端隐藏无权操作的控件，后端仍对每次读取和命令重新鉴权。

新建草稿时选择服务并填写名称、负责人和 Runbook key。当前执行器仅注册 `demo-http / recover_connection_pool`：风险 R1、单实例参数范围、恢复步骤、健康查询和空回滚保持固定；表单明确显示这些约束。可修改支持范围内的验证次数、间隔和说明文档。只读 JSON 用于核对，不替代表单，也不能用来绕过后端白名单。

草稿保存使用资源 revision；独立评审人不能是作者或最后编辑者。发布前检查结构差异、验证规则及作用范围，并确认发布。已发布版本不可原地修改，只能创建下一草稿。收到 412 时保留本地编辑，先检查服务器的新版本再决定如何修改，不自动覆盖他人修改。

保存、评审和发布发送 `If-Match` 与 `Idempotency-Key`；创建发送 `Idempotency-Key`。结果不确定时冻结表单并使用原请求重试，明确失败后修正或新的操作使用新的键；切换版本会清理旧页面的命令状态。后端版本、职责分离和发布原子性记录见 [Stage 2A 实施记录](stage-2a-progress.md)。

## 证据详情

点击事故证据旁的“查看详情”，按需读取对应事故下的一条快照。界面展示来源、查询标识、采集时间、查询窗口、完整内容哈希、截断状态和脱敏规则/次数。历史记录缺少查询窗口时明确标为未记录，不根据采集时间推测。

正文仅显示服务器提供的脱敏 JSON 文本，不执行其中的 HTML 或指令。长内容先显示前 20,000 字符，可主动展开；“采集已截断”与界面的折叠状态分别表示。Esc 关闭抽屉并回到触发按钮。

## AI Eval

仅 `PLATFORM_ADMIN` 可读取报告、运行历史或发起评测。选择同一数据集的已完成运行作为可选基线，使用固定 `incidents-v1` 数据集运行评测。运行期间轮询只读状态，不自动重发创建命令。

发布结论直接显示后端的 `releaseAllowed`。引用率、危险动作拦截率、Runbook 准确率、根因 Top-3 准确率和虚构项计数逐项显示阈值；安全失败不会被平均分掩盖。缺失指标标为不可用，未知价格/用量不显示为零费用。

趋势仅使用已完成的真实运行，按运行时间排序，准确率、延迟与费用使用独立单位；同时保留可访问的数据表。失败详情显示 case ID 和稳定错误码，不展示原始 prompt 或模型响应。指纹和基线差异用于追溯固定配置，具体评分与基线限制见 [AI Eval](ai-evaluation.md)。

治理页面与 ECharts 按需加载。会话、Token 或授权变化后使用新的不透明缓存范围；身份或授权切换会清空页面本地编辑状态，同一用户权限未变时的 Token 自动续期保留未保存输入。Token 只发送在请求头中，不作为查询缓存键。
